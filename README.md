# FISIMATE - Portal Siswa : Physics Mobile Learning Platform Integrated with Game Engine & Generative Artificial Intelligence

**FISIMATE - Portal Siswa** is a physics mobile learning platform dedicated for Indonesian High School (SMP-MTs-MAN-SMK) to introducing innovative and fun way to learn physics. Utilized Flutter framework, Unity game engine, and Google Gemini GenAI to built customized and interactive learning methods. Successfully tested on 38 middle school students, achieving a user satisfaction score of 89.73%. This project is a collaboration between the FISIMATE project team, Informatics Engineering faculty members from Politeknik Negeri Semarang, and SMK Negeri 3 Kendal, as part of the university's community service efforts, particularly towards educational institutions.
